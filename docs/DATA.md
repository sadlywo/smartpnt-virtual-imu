# Data Notes

This project uses two data modes.

## Simulation Data

Simulation data is generated by `scripts/make_sim_data.py` and stored under `data/processed/sim`.
Each split is a Parquet file with standardized columns:

- `timestamp_s`
- `gx_low`, `gy_low`, `gz_low`
- `ax_low`, `ay_low`, `az_low`
- `gx_high`, `gy_high`, `gz_high`
- `ax_high`, `ay_high`, `az_high`
- `temperature_c`
- `motion_label`
- `sequence_id`

Simulation is the default reproducibility path and does not require external downloads.

## SmartPNT-MSF Data

Raw SmartPNT-MSF data should be placed under `data/raw/smartpnt`. The project intentionally does not assume the final schema before inspection. Use:

```bash
uv run python scripts/inspect_dataset.py --root data/raw/smartpnt --out outputs/smartpnt_inspection.md
```

After inspection, configure `configs/smartpnt_example.yaml` with the low/high IMU files and columns, then run preparation.

## Manifests

`data_manifest.json` records source URL, download time, local path, file count, file sizes, and optional SHA256 hashes. Generated manifests live next to downloaded raw data and are not committed.
