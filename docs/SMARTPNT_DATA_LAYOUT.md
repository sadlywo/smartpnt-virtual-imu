# SmartPNT-MSF Local Data Layout

Use this layout for manually downloaded SmartPNT-MSF data.

```text
data/
  raw/
    smartpnt_msf/
      00_archives/          # Put original .zip/.rar/.7z downloads here. Do not edit.
      01_extracted/         # Extract complete SmartPNT-MSF folders here. Preserve original names.
      02_groundtruth_only/  # Optional copies of GroundTruth files for quick GT checks.
      _manifests/           # Local checksums, download notes, and source records.
  processed/
    smartpnt_msf/           # Prepared Parquet splits and aligned tables generated by scripts.
outputs/
  smartpnt_msf/             # Inspection reports, preparation reports, metrics, and figures.
```

Recommended placement:

1. Keep Baidu Netdisk archives unchanged in `data/raw/smartpnt_msf/00_archives/`.
2. Extract each archive into `data/raw/smartpnt_msf/01_extracted/`.
3. Preserve the dataset folder names from the archive. Do not rename sensor files before inspection.
4. If a sequence contains `GroundTruth/IMU_(GT).txt` or `GroundTruth/ROVE_(GT).txt`, keep it in place. Optional convenience copies may also go under `02_groundtruth_only/`.
5. Run:

```bash
uv run python scripts/inspect_dataset.py --root data/raw/smartpnt_msf/01_extracted --out outputs/smartpnt_msf/inspection.md
```

After inspection, set `low_imu_source`, `high_imu_source`, and `ground_truth_source` in `configs/smartpnt_example.yaml` using paths relative to `raw_root`.
